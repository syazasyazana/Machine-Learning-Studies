# Machine-Learning-Studies

“Analyzing Student Perspective: A Machine Learning Approach into Students’ Online Learning Adaptability,” explores how well students adapt to online learning using machine learning models. Using a dataset from Kaggle, the study analyzes adaptability levels with five classification models: Fast Tree, XGBoost, CatBoost, L1 Regularization, and LightGBM. The Fast Tree model achieved the highest accuracy (0.91), indicating strong predictive performance.

The research applies various statistical and machine learning techniques to identify key sociodemographic and environmental factors (like internet type, location, and financial condition) that influence adaptability. It uses descriptive statistics, model evaluation metrics (accuracy, F1-score, precision), and statistical tests (t-tests, confidence intervals) to validate results.

The findings provide actionable insights for educators and policymakers to design more inclusive and adaptive online learning environments, particularly helpful in post-pandemic education planning.
